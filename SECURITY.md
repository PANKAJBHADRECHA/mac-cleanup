# Security policy

## Reporting a vulnerability

Please use GitHub's [private vulnerability reporting](https://github.com/PANKAJBHADRECHA/mac-cleanup/security/advisories/new) for issues involving unintended deletion, path escapes, symlink handling, or exposure of local data. Do not disclose a reproducible deletion issue in a public issue before it has been reviewed.

Include the affected version, macOS version, expected and observed behavior, and reproduction steps using disposable temporary fixtures. Redact usernames, personal filenames, process arguments, and other private data. Never attach credentials or personal cleanup logs.

This is an independently maintained project without a guaranteed response time. The latest release is the target for fixes; older releases do not receive separate maintenance branches. See [Safety and privacy](docs/SAFETY.md) for current limitations and [Releases](https://github.com/PANKAJBHADRECHA/mac-cleanup/releases) for updates.
